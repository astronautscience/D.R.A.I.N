Hey new AI! Welcome to the project. Here's everything you need

── WHAT THIS PROJECT IS ──
A 3D dinosaur exploration/learning game built in a SINGLE
index.html file. The player walks around in third-person,
discovers dinosaur species, reads facts, takes quizzes to earn
gems, takes photos, and watches realistic dinosaur AI behaviors.
There are now TWO BIOMES with 10 total species.

── TECH STACK ──
- Three.js r160 from unpkg CDN (via importmap)
- Single index.html file (the ONLY file that matters)
- No build tools, no npm, no node on this machine
- Opens from file:// with internet for CDN
- Addons: OrbitControls, Sky, EffectComposer, RenderPass,
  UnrealBloomPass

── CURRENT FEATURES (all working) ──
- WASD third-person movement with sprint (Shift)
- OrbitControls camera following player
- TWO BIOMES with smooth transition:
    JURASSIC FOREST (center, x < ~80):
      Lush green terrain, river, pond, conifers, ferns, grass
    CRETACEOUS DESERT (east, x > ~110):
      Sandy dunes, mesas, dry riverbed, dead trees, scrub
- 10 species with procedural 3D models (ALL airbrush style):
    Jurassic Forest (7):
      1. Brachiosaurus (rare, huge herbivore)
      2. Stegosaurus x2 (uncommon, large herbivore)
      3. Diplodocus (rare, huge herbivore)
      4. Compsognathus x4 (common, tiny carnivore)
      5. Archaeopteryx x2 (uncommon, tiny omnivore)
      6. Allosaurus (rare, large carnivore - DANGER)
      7. Ceratosaurus (uncommon, medium carnivore - DANGER)
    Cretaceous Desert (3):
      8. Triceratops x2 (uncommon, large herbivore)
      9. Velociraptor x3 (rare, small carnivore - DANGER)
     10. Parasaurolophus x2 (uncommon, large herbivore)
- Biome HUD indicator (changes when crossing biomes)
- Fog color shifts per biome (green fog vs amber fog)
- Proximity-based discovery system with gem rewards
- Dino Index (Tab key OR INDEX button) with species list,
  facts, freeform notes, photos
- Quiz system (Q key OR QUIZ button on screen):
    - Multiple choice and true/false questions
    - Earn 5 gems per correct answer
    - QUIZ button pulses after discovering a new species
    - Prefers questions about most recently discovered dino
- Photo snapshots (P key) saved to Dino Index
- Danger zone system with red vignette for predators
- Realistic AI: hunger-driven hunting, territorial behavior,
  grazing, resting, wandering (NO aimless killing)
- Desert dinos stay in the desert (sp.biome='desert')
- World size: 400x400 (HALF=200)
- Procedural terrain with 200 segments
- Animated water, 5000 instanced grass blades
- Sky addon, env map, bloom post-processing, golden hour lighting
- Procedural audio (footsteps, discovery jingle, roars, ambient)
- Gem counter with sessionStorage persistence for notes

── IMPORTANT USER PREFERENCES ──
- Dinosaurs should NOT aimlessly kill each other
- They should only hunt when hungry, fight for territory,
  or occasionally spar
- User wants things "extremely realistic" / "hyper realistic"
- ALL dinosaur materials use AIRBRUSH style (smooth gradients,
  low bump, high clearcoat ~0.45, roughness ~0.3, subtle glow)
- Keep it in a single HTML file
- No build tools available (no npm, no node, no python)

The file is ~900+ lines. Approximate layout:
  - HTML + CSS + importmap + body elements (buttons, HUD,
    modals, quiz overlay, biome indicator)
  - JS imports + geometry helpers (mkS, mkB, mkC, mkCone, P)

    All using airbrush: radial gradients, soft blending
  - Constants (WORLD=400, HALF=200, GEM_REWARDS, RARITY_COLORS)
  - SPECIES data (10 species with facts, quiz Qs, colors)
  - getBiome() — returns biome type and blend factor for x,z
  - terrainH() — blends forest + desert heightmaps

  - Vegetation (conifers, broadleaf, ferns, rocks, grass)
  - Desert vegetation (dead trees, scrub, desert rocks)
  - 10 dinosaur model builder functions (all airbrush materials)
  - Player model builder
  - Audio system (procedural sounds)
  - DinoEntity AI class (states: IDLE, WANDER, GRAZE, REST,
    HUNT, TERRITORIAL + animation)
  - logEvent UI helper
  - Game class:
    - Scene setup (renderer, camera, controls, sky, env map,
      lighting, post-processing)
    - World building (terrain, water, vegetation, desert stuff)
    - Player spawning + dino spawning (forest + desert)
    - Discovery system, quiz system, photo system

    - Game loop
